# Abstract

<!-- * Summary of the nature, finding and meaning of your data analysis project.
* 1 paragraph written summary of your data analysis project -->

This project explores the prediction of electronic band gaps in hypothetical perovskite materials using the `castelli_perovskites` dataset provided by the `Matminer` library. Using machine learning techniques, we aim to establish quantitative relationships between crystal structures of perovskites and their band gaps.

# Introduction

<!-- * Background and motivation of the Data Science question. The ``Why'' of the research
* Explanation of your data
  * Where is your data from
  * What are the variables
* What data would be necessary to improve your analysis? -->

The growing demand for energy has led to an increased interest in perovskite materials due to their diverse physical and chemical properties. An important property of interest is the electronic band gap, which determines the material's function as a semiconductor.

For this project, we will use the `castelli_perovskites` dataset from the `Matminer` library. This dataset provides us with band gaps (gap gllbsc), crystal structures, absolute band edge positions and heat of formation, and other material properties for 18,928 perovskites generated by ABX combinatorics. Our goal is to use compositional and elemental features to train regression models that accurately predict band gaps and enable rapid screening of new perovskite material candidates.

* Data Source: [Matminer `castelli_perovskites` dataset](https://hackingmaterials.lbl.gov/matminer/dataset_summary.html#castelli-perovskites).

* Variables: **chemical formula** (feature), **bandgap** (target).

# Data Science Methods

<!-- * To be applied (such as image processing, time-series analysis, spectral analysis etc)
* Define critical capabilities and identify packages you will draw upon -->


In this project, we apply a graph-based machine learning approach using the MEGNet framework to predict the electronic band gap (gap gllbsc) of perovskite materials. The process consists of the following steps:

* Packages and Tools

  We use the following packages throughout the project:

  * `matminer`: to load the castelli_perovskites dataset.

  * `pymatgen`: for handling and manipulating crystal structures (Structure objects).

  * `megnet`: the core framework for constructing graph-based models and predicting properties.

  * `numpy`, `pandas`: for data handling and preprocessing.

  * `scikit-learn`: for performance metrics and basic data splitting.

  * `matplotlib`: for visualization.

* Data Preparation:

  * We use the `castelli_perovskites` dataset available from the `Matminer` library, which contains crystal structure information in the form of pymatgen Structure objects.

  * Entries with missing or invalid band gap values are removed.

  * A subset of the data is selected to keep computational demands suitable for `Google Colab`.

* Graph Construction:

  * Each material is represented as a graph, where atoms are nodes and interatomic interactions (within a cutoff radius) are edges.

  * We utilize MEGNet’s built-in graph converter that processes pymatgen Structure objects directly into input graphs for the model.

* Modeling:

  * The MEGNet model is used for regression, with the band gap as the target variable.

* Model Evaluation:

  * Model performance is assessed using:
    * Mean Absolute Error (MAE)
    * Root Mean Squared Error (RMSE)
    * R² score
  * We split the data into training and validation sets.

This method enables structure-aware band gap prediction and provides physical insight into how atomic environments affect electronic properties in perovskite materials.

- To explore the relationship between material features and the band gap (gap gllbsc), we applied two types of supervised learning models: a simple linear regression and a non-linear ensemble model (Random Forest Regressor).

## Model selection

- Linear Regression
  - A baseline model was constructed using a standard linear regression on all numerical features, including physical properties (e_form, mu_b, etc.) and atomic fractions derived from composition.
- Random Forest Regression
  - To capture potential non-linear relationships, we trained a Random Forest model with default parameters, using 5-fold cross-validation to ensure generalization.

# Discussion

<!-- * Discussion of the answers to the data science questions framed in the introduction -->
  
- The primary research question was: Can we predict the electronic band gap of materials from basic physicochemical and compositional descriptors?
- Our analysis confirms that:
  - Simple linear models are insufficient for capturing the complex, often non-linear relationships present in band gap formation.
  - Random Forest models are capable of learning these complex patterns with significantly improved predictive accuracy.
  - Permutation importance provides a robust and interpretable method to assess which features most influence the target variable.
  - Compositional features, derived automatically from chemical formulas, offer a lightweight yet powerful representation of materials for modeling purposes.
  - However, the relatively modest R² score (~0.54) suggests there is still significant unexplained variance, possibly due to missing structural features or higher-order interactions not captured in the model.

# Conclusions

- This study demonstrates the viability of machine learning approaches in materials informatics, specifically for band gap prediction in perovskite-like materials.
  - Random Forests provided the best performance among the tested models, indicating the presence of non-linear effects.
  - Formation energy and magnetic moment emerged as the most critical features, alongside key elemental fractions.
  - The methodology successfully leverages composition-only descriptors, making it suitable for large-scale screening where structural data may be unavailable.
- In future work, model performance may be further enhanced by:
  - Integrating crystal structure descriptors (e.g., space group, density).
  - Exploring advanced models such as Gradient Boosting, SHAP interpretation, or even GNNs.
  - Performing uncertainty quantification to guide experimental validation.
